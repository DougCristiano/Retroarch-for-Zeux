# RetroArch for ZeuX — mirror não-oficial

Este repositório redistribui um build **oficial e sem modificações** do
[RetroArch](https://www.retroarch.com/), usado como fonte de instalação
automática (1-click) pelo [ZeuX](https://github.com/DougCristiano/ZeuX).

**Este repositório não é afiliado, endossado ou mantido pelo projeto RetroArch
ou pela equipe Libretro.** "RetroArch" é um nome do projeto original — este
mirror existe apenas para contornar a ausência de uma API estável de releases
no buildbot oficial (buildbot.libretro.com).
